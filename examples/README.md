# Examples

Reference federates demonstrating the RTI in use.

| Directory | Owner | Milestone | Purpose |
|---|---|---|---|
| `go-pingpong/` | Agent A | M2 | Two in-process Go federates exchanging interactions; deterministic across 10 runs. |
| `go-timed/` | Agent A | M3/M21 | Three cross-process Go federates advancing with TAR and different lookaheads. |
| `go-tar-wait/` | - | - | Two cross-process Go federates demonstrating a TAR grant blocked until a peer advances. |
| `pitch-chat-parity/` | - | - | Two Python federates implementing the Pitch pRTI Evolved C++/Java Chat semantic contract. |
| `pyjevsim/` | Agent C | M4 | Two pyjevsim coupled models, one RTI; deterministic across 10 runs. |

These directories will be created during their respective milestones; M0 ships only this README.
