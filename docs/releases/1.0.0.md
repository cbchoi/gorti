# gorti 1.0.0

Released 24 October 2026 as a
[source archive](https://github.com/cbchoi/gorti/releases/tag/1.0.0).
The tag is `1.0.0`, without a `v` prefix.

## Included software

- A standalone Go RTI server targeting the IEEE 1516-2010 HLA family.
- Go, Python, and Java federate interfaces, with Float64 and Integer64 time.
- Federation, declaration, object, time, ownership, DDM, synchronization,
  save/restore, MOM, and Support services.
- LocalLRC receive-order transport and optional asynchronous callback reporting.
- Model adapters, Windows/Linux example launchers, modular service code,
  SRS/SDD/IDD/STD documents, and requirement-derived tests.

The default HLA core profile has no audit journal. Audit/replay is optional.
The supported topology uses one authoritative server. Retained C++ and
cluster material is outside the supported release profile.

## Build and use

Follow [installation](../installation.md), then run the two-federate
[quickstart](../quickstart.md) or the [Python-Go model](../model-integration.md).
This source release does not publish prebuilt binaries, a PyPI wheel, or
Maven Central artifacts. The Python source package version is 1.0.0; the Java
reactor retains its independent `0.1.0-SNAPSHOT` artifact version.

## Recorded validation

The [19 October service campaign](../verification.md) assessed source
`4b11da4`. RTI and SDK behavior and linked service-test sources are unchanged;
later commits add examples, result tools, documentation, and release metadata.
The release does not claim a new full service campaign or whole-standard
certification. Skips and unresolved requirement records remain listed.

The Python-Go example has nine retained reference-matching executions.
The [Portico comparisons](../performance.md) are historical 7-8 October
measurements, not performance measurements of this release.
