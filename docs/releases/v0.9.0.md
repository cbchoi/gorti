# gorti v0.9.0 — HLA Evolved conformance release

First public release with the complete IEEE 1516-2010 service surface and
a locally enforced conformance program. License: MIT.

## Headlines

- **Spec-strict IEEE 1516.1-2010 DLC C++ SDK** (`cppsdk`): the standard
  `RTI/…` header surface, source-compatible with federates written for any
  DLC-conformant RTI (Pitch, MAK, Portico). Locked by ~200 compile-time
  assertion TUs, 121 runtime-tested Annex C exceptions, 53 callback-bridge
  tests, 36 encoding round-trips.
- **27/27 behavioral conformance fixtures at FULL/SPEC-FULL** — every HLA
  service group exercised end-to-end against a live `rtid`, with verdicts
  as canonicalized-event comparisons against spec-derived goldens. Three
  goldens (within the free-edition federate cap of a reference RTI) were
  additionally cross-checked locally and confirmed byte-for-byte identical
  after canonicalization; the rest are derived directly from IEEE spec
  §-sections. The PRTI_HOME-gated harness allows anyone with a DLC-
  conformant RTI to independently reproduce the cross-check. Scoreboard +
  caveats: `docs/PITCH_PARITY.md`.
- **Local conformance gate** (`scripts/ci-gates.sh`): stubs → go → cpp →
  lockfile → static → sweep → ivct before releases and significant
  changes. Fixture verdicts are pinned in
  `EXPECTED_VERDICTS.txt` and enforced in both directions — regressions
  AND unrecorded improvements fail.
- **IVCT-inspired Python conformance subset**: 35 tests, 0 xfail
  (honest scoping: IVCT-*inspired*, not IVCT — see
  `tests/conformance/rti/ivct-subset/README.md`).
- **Cross-language byte identity proven live**: a Python publisher's
  HLA-encoded attributes decoded byte-identically by a C++ DLC subscriber
  (`xlang_python_cpp_pubsub`).

## Service-surface highlights (vs the MVP tag)

- Time management: TAR/TARA/NER/NMRA/FQR with §8.10 exact-time grants,
  §8.8 next-message grants (no interim grants), §8.14 TSO-before-grant
  delivery, §8.15 tie-break order, outgoing-TSO validation.
- Ownership: real §7.6 two-phase negotiated divestiture
  (ConfirmDivestiture RPC), atomic §7.9 acquire-if-available, §7.11
  release requests, per-instance §6.6 update-ownership enforcement.
- DDM: region-scoped pub/sub with DDM-aware discovery and §6.17/§6.18
  scope advisories.
- MOM: HLAmanager object-instance fan-out (federation/federate instances,
  retroactive discovery) + HLArequest/HLAreport interactions.
- Federation management: save/restore (restore-by-name), sync points with
  §4.12 acks and §4.15 failure sets, list-federations reporting.
- §8.22 message retraction with real retraction handles.
- FR-DLC-14 callback re-entrancy guard (CallNotAllowedFromWithinCallback).
- Structured exception channel: gRPC trailing metadata
  `rti-spec-exception` carrying the Annex C exception class name;
  both SDKs map it metadata-first (string sniffs are a deprecated
  fallback). Contract for SDK authors: `cppsdk/src/dlc/README.md`.
- pysdk: full FederateEvent wire coverage with a drift guard, typed
  handles alongside legacy forms, Annex-C-named exceptions, Layer-2 API
  completeness (destroy, typed create, ownership flags).

## Known limitations (read before adopting)

- **No Java federate SDK** — Java federates cannot connect. This is the
  main gap vs commercial RTIs; a Java track (and with it, real IVCT
  integration) is future work.
- **Single-node**: cluster/failover code exists but is demo-grade
  (gossip-based, no Raft); treat multi-node as experimental.
- **Scale**: the M5 perf baseline (see README) is in-process; large
  distributed federations are unbenchmarked.
- Spec-derived goldens are cross-validated locally against live gorti, but
  large-scale cross-validation against other DLC-conformant RTIs (Portico,
  MAK, Pitch Pro) is future work. The three goldens within the free-edition
  federate cap were locally confirmed byte-for-byte identical to a reference
  RTI after canonicalization; that cross-check is reproducible via the
  PRTI_HOME-gated harness for any user with a licensed RTI.
- HLA 1.3 / 1516-2000 / HLA 4 interfaces are out of scope.
- The IVCT subset is IVCT-inspired, not IVCT certification.
