# gorti v0.9.0 release candidate

v0.9.0 is the first public release candidate. It implements a substantial
IEEE 1516-2010 service subset, but the SDKs do not expose identical APIs and
the project does not claim complete standard coverage or formal IVCT
certification. The release uses the MIT license.

## Included in this candidate

- A single-node Go `rtid` server and Go, Python, and C++ federate SDKs.
- A DLC-shaped C++17 API for the maintained Linux and macOS profile. Its tests
  cover the public header shape, 121 Annex C exception classes, callback
  bridging, and HLA encoding round trips.
- Twenty-seven live behavioral fixtures covering every implemented service
  group. Expected verdicts are stored in `EXPECTED_VERDICTS.txt` and checked
  against canonical event logs.
- An IVCT-inspired Python subset with 35 passing tests. It is a local
  conformance aid, not IVCT certification.
- A live Python-publisher/C++-subscriber fixture that compares encoded
  attribute bytes across SDKs.
- The local `scripts/ci-gates.sh` release gate for generated code, Go, C++, API
  lockfiles, static checks, fixture sweeps, and the IVCT-inspired subset.

## Service coverage added since the MVP

- **Time management:** TAR, TARA, NER, NMRA, FQR, exact-time and next-message
  grants, TSO delivery before grants, deterministic tie breaking, and outgoing
  timestamp validation.
- **Ownership:** negotiated divestiture, atomic acquire-if-available, release
  requests, and per-instance update checks.
- **DDM:** region-scoped publication and subscription, DDM-aware discovery, and
  scope advisories.
- **MOM:** federation and federate object instances, retroactive discovery,
  and request/report interactions.
- **Federation management:** save and restore, synchronization failure sets,
  and federation-execution listing.
- **Object management:** message retraction with retraction handles.
- **C++ callbacks:** re-entry checks and Annex C exception names carried in
  `rti-spec-exception` trailing metadata. See `cppsdk/src/dlc/README.md`.
- **Python SDK:** typed handles, named exceptions, broader callback coverage,
  and dedicated service clients.

The exact API differences between SDKs are recorded in the current IDD.

## Verification status

All retained fixtures run against a live `rtid` and compare canonicalized
events rather than console text. Three two-federate golden traces were also
cross-checked against a licensed reference RTI and matched after
canonicalization. The remaining goldens are derived from the corresponding
IEEE service requirements. Users with a conformant reference installation can
repeat the external comparison through `verification/commercial-rti`.

Release counts are snapshots, not permanent claims. Before tagging, rerun the
Go suite, Python Ruff/mypy/pytest checks, Buf lint and breaking checks, strict
MkDocs build, example entrypoint validation, and the C++ conformance gate on
its maintained Linux toolchain. Record the commit and tool versions with the
release evidence.

## Known limitations

- There is no Java federate SDK.
- One authoritative `rtid` node is the supported deployment. Cluster and
  failover code is experimental.
- Performance evidence uses two independent federate processes in a small
  two-federate federation. Large federations have not been benchmarked.
- Broader cross-validation against other conformant RTIs is still required.
- HLA 1.3, IEEE 1516-2000, and HLA 4 APIs are outside this release.
- The test subset inspired by IVCT is not formal IVCT certification.
