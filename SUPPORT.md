# Support

Use the [issue tracker](https://github.com/cbchoi/gorti/issues) for usage
questions, design discussions, reproducible bugs, and feature requests. Start
the issue title with `Question:`, `Bug:`, or `Feature:` so it can be triaged
quickly.

Include the gorti version, operating system, command line, FOM modules, and a
minimal reproduction. Remove credentials and private federation data before
posting logs.

Security reports follow the private process in [`SECURITY.md`](SECURITY.md).
