# Support

Use [GitHub Discussions](https://github.com/cbchoi/gorti/discussions) for usage
questions and design conversations. Use the
[issue tracker](https://github.com/cbchoi/gorti/issues) for reproducible bugs
and feature requests.

Include the gorti version, operating system, command line, FOM modules, and a
minimal reproduction. Remove credentials and private federation data before
posting logs.

Security reports follow the private process in [`SECURITY.md`](SECURITY.md).
